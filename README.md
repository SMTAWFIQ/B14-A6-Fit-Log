# FitLog

# About FitLog

FitLog is a modern fitness and workout management web application built with Next.js and React. It helps users discover workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

Users can browse workouts, sort them by different criteria, add exercises to their Today's Plan, save workouts, mark exercises as completed, and manage their workouts from a simple and responsive dashboard.

The application uses React Context API for global state management and provides a smooth user experience with responsive design, toast notifications, loading states, dynamic routing, and a custom 404 page.

## Technologies Used

- Next.js (App Router)
- React
- Tailwind CSS
- DaisyUI
- React Context API
- React Hooks
- React Toastify
- JavaScript (ES6+)
- FitLog REST API

## Key Features

1. **Workout Library** — Browse all workouts in a responsive grid with workout images, muscle groups, equipment, difficulty, duration, calories, and rating.

2. **Sort Workouts** — Sort workouts by Duration, Calories, or Rating.

3. **Detailed Workout Pages** — View detailed information about each workout, including specifications, description, and step-by-step instructions.

4. **Today's Plan & Saved Workouts** — Add workouts to today's plan or save them for later.

5. **Live Navbar Counters** — Plan and Saved counters update automatically when workouts are added or removed.

6. **My Plan Dashboard** — Manage today's workouts and saved workouts from a dedicated dashboard with separate tabs.

7. **Workout Management** — Mark workouts as completed or remove them from the plan.

8. **Toast Notifications** — Get instant feedback when adding, saving, completing, or removing workouts.

9. **Dynamic Routing** — Each workout has its own dynamic route using Next.js App Router.

10. **Loading State** — Display a loading UI while workout data is being fetched.

11. **Custom 404 Page** — Show a user-friendly 404 page for unknown or invalid routes.

12. **Active Navigation** — Highlight the currently active navigation link using `usePathname()`.

13. **Global State Management** — Manage and share plan and saved workout data across components using React Context API.

14. **Responsive Design** — Fully responsive UI for mobile, tablet, and desktop devices.
